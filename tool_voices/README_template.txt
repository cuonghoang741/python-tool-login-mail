========================================
   TOOL VOICE CLONING & SYNTHESIS
========================================

Cong cu nhan ban va tong hop giong noi
su dung cong nghe AI tien tien.

========================================
   HUONG DAN SU DUNG
========================================

1. Neu lan dau tien chay, double-click install_python.bat
   de cai dat Python 3.11 (neu chua co)

2. Double-click file ToolVoiceCloning.exe
   de khoi dong ung dung

2. Tab "Upload & Train":
   - Upload file audio giong noi
   - Huan luyen mo hinh nhan ban giong

3. Tab "Synthesize":
   - Chon giong da train
   - Nhap van ban can tong hop
   - Tao file audio output

========================================
   YEU CAU HE THONG
========================================

- Windows 10/11
- Python 3.11 (se duoc cai dat tu dong neu chua co)
- Khong can cai dat phan mem khac

========================================
   CAU TRUC THU MUC
========================================

- ToolVoiceCloning.exe  : File chay chinh
- venv_voice\            : Moi truong Python & thu vien
- tool_voices\           : Source code
- config\                : File cau hinh
- voices\                : Giong noi da train
- outputs\               : File audio output
- logs\                  : File log

========================================
   HO TRO
========================================

Neu gap van de, vui long kiem tra:
- File logs\app.log de xem loi chi tiet
- Dam bao thu muc khong bi di chuyen hoac xoa file
